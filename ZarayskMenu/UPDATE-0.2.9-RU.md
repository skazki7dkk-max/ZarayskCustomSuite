# Warcraft 4.2.0-zaraysk-0.2.9

Исправлено нативное падение при входе игрока в команду с сохранённым классом
Tinker. Серверная консоль заканчивалась на `ChangeTeam`, а перед этим база
загружала `raceName=tinker`.

- Tinker больше не создаёт физические дроны и не выдаёт decoy во время
  `ChangeTeam`/появления pawn.
- Старые событийные обработчики Tinker отключены, чтобы исключить повторный
  запуск небезопасного кода при spawn.
- Ульта Tinker заменена на безопасный «Аварийный ремонт»: +35 здоровья и +50
  брони с сохранением стандартного cooldown.
- Старые событийные обработчики Necromancer также отключены. Безопасная ульта
  некроманта остаётся привязана.
- Остальные исправления 0.2.8 сохранены.

## Установка

1. Полностью остановить сервер.
2. Скопировать папку `game` из архива в папку `game` сервера с заменой файлов.
3. Удалить старый файл
   `addons/counterstrikesharp/plugins/WarcraftPlugin/ZarayskWarcraftFixes.dll`,
   если он остался от ранних сборок.
4. Запустить сервер без hot reload.
5. `css_plugins list` должен показать
   `Warcraft (4.2.0-zaraysk-0.2.9)`.

Обновление содержит только WarcraftPlugin.dll, исходный deps.json и общую
ZarayskMenu.Api.dll. Остальные файлы установленного пакета сохраняются.
