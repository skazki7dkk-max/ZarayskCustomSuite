# Обновление 0.2.2: сайт скинов и выдача опыта

## Меню скинов

В разделе «Скины и аксессуары» пункты оружия, перчаток, агентов, музыки, значков и наклеек выводят в чат:

> Скины вы можете настроить на нашем сайте cszaraysk.net/skins

Меню при этом остаётся открытым. Ножи и питомцы открывают свои игровые окна. Прямые команды WeaponPaints не менялись: запрос касается пунктов общего меню.

## Опыт Warcraft

В **консоли игры**, будучи подключённым к серверу:

```text
css_warxp 5000
```

Выдаёт 5000 XP вашему текущему классу. Требуется флаг администратора CounterStrikeSharp `@css/addxp` либо `@css/root` в существующем admins.json. Обычным игрокам команда недоступна. Новые права автоматически никому не выдаются.

В **консоли сервера или RCON** у команды нет понятия «я», поэтому укажите SteamID64 подключённого игрока:

```text
css_warxp 5000 ВАШ_STEAMID64
```

Замените ВАШ_STEAMID64 своим числовым SteamID64 без кавычек. Игрок должен быть онлайн. Выдача допускает от 1 до 1000000 XP за вызов. Максимум класса — 16-й уровень; команда не снимает этот предел. Используется штатный метод Warcraft AddXp: он повышает уровни и отмечает прогресс для штатного сохранения. Результат выводится в консоль, выдача записывается в журнал. Очки навыков затем распределите через меню Warcraft.

## Установка поверх 0.2.1

Остановите сервер и скопируйте содержимое `server/game/csgo/` из маленького архива обновления в `game/csgo/` сервера. Обновляются только:

- `addons/counterstrikesharp/plugins/ZarayskMenu/menu.json`;
- `addons/counterstrikesharp/plugins/ZarayskWarcraftMenu/ZarayskWarcraftMenu.dll`;
- `addons/counterstrikesharp/plugins/ZarayskWarcraftMenu/ZarayskWarcraftMenu.deps.json`.

Если вы редактировали menu.json, сначала сохраните копию и перенесите изменения раздела skins вручную. Базы, конфиги Warcraft/WeaponPaints, Linux-исправление SQLite и общая API этим маленьким обновлением не заменяются. Запустите сервер заново.

Полный архив 0.2.2 также включает исправления Linux и адаптированный WeaponPaints из 0.2.1. Номер ядра остаётся 0.2.1: исполняемый код ядра не изменён; модуль ZarayskWarcraftMenu — 0.2.2.

Проверено: сборка, конфигурация шести пунктов и исключений, границы и некорректные аргументы XP, существующие проверки интеграций. На живом сервере команда выдачи опыта здесь не выполнялась.
