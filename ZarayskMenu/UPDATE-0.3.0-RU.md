# Warcraft 4.2.0-zaraysk-0.3.0

- Восстановлены все обычные навыки и событийные обработчики Tinker.
- Восстановлены все обычные пассивы и события Necromancer.
- Заменена только подтверждённо аварийная ульта Tinker: вместо роя физических
  сущностей она даёт +35 здоровья и +50 брони с cooldown 50 секунд.
- `!helpwar` обновлён: описания Tinker и Necromancer теперь соответствуют DLL.
- Добавлен `WARCRAFT-CHECKLIST-0.3.0-RU.md` с командами и проверкой 14 классов.
- Сохранены исправления урона, рывка Ranger, модели Barbarian, SQLite и
  автоматического hot reload.

## Установка

1. Полностью остановить сервер.
2. Скопировать `game` из архива в серверную папку `game` с заменой.
3. Удалить `plugins/WarcraftPlugin/ZarayskWarcraftFixes.dll`, если старый файл существует.
4. Запустить сервер без hot reload.
5. Проверить `css_plugins list`: версия Warcraft должна быть `4.2.0-zaraysk-0.3.0`.
