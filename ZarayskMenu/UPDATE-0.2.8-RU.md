# Warcraft 0.2.8 — отключение самоперезагрузки

Обновление устанавливается поверх полного комплекта ZarayskMenu 0.2.2/0.2.3
с WarcraftPlugin 4.2.0. Другие сборки Warcraft не поддерживаются.

## Установка

1. Полностью остановите сервер. Hot reload не использовать.
2. Сохраните копию `game/csgo/addons/counterstrikesharp/plugins/WarcraftPlugin`.
3. Скопируйте папку `game` из архива в корень сервера с заменой.
4. Запустите сервер.

## Исправления

- Удалён вызов `CBaseEntity_TakeDamageOldFunc` из урона навыков. Присланный
  `warcraft-breadcrumbs.log` показывает серии атак некроманта, заканчивающиеся
  непосредственно на `Invoking native TakeDamage function`. Официальный API также
  помечает эту функцию устаревшей.
- Нелетальный урон теперь безопасно меняет `m_iHealth` и отмечает сетевое поле
  изменённым. Летальный урон запускает поддерживаемый API `CommitSuicide`.
- Цена стабильности: убийство от способности может показываться в таблице как
  самоубийство, а не как убийство владельцем навыка. Урон и смерть работают,
  но точная иконка и начисление фрага атакующему для летального тика не гарантируются.
- Автоматическая выдача дыма некроманту на событии spawn отключена: она повторно
  входила в нативный перехват оружия, пока инвентарь игрока ещё создавался.
  Дым можно купить или подобрать обычным способом; `EventItemEquip` продолжает
  превращать его в ядовитое облако.
- Для классов без ограничений оружия добавлен ранний выход до нативного поиска
  данных оружия. У некроманта список ограничений пустой.
- Старая ульта некроманта полностью удалена: она создавала 10 `CChicken`, меняла
  их владельца, AI-лидера и скорость каждые 0,1 секунды. Боты автоматически
  используют эту ульту при появлении противника, поэтому падение могло совпадать
  с выбором команды игроком.
- Новая «Армия мёртвых» не создаёт AI-сущности. В течение 10 секунд она раз в
  секунду наносит 8 урона противникам в радиусе 350 единиц вокруг некроманта.
- Отключена проверка `CustomHeroes`, которая каждые 5 секунд могла менять время
  `WarcraftPlugin.dll` и инициировать hot reload. Во всех присланных свежих логах
  последним событием перед отказом было `Unloading ... (hotReload=True)`.
- Версия в логе изменена на `4.2.0-zaraysk-0.2.8`. Это позволяет однозначно
  проверить, что сервер загрузил новую DLL, а не оставил предыдущую сборку.
- `WarcraftPlugin.deps.json` восстановлен из оригинального Warcraft 4.2.0 без
  добавленной зависимости. Присланный свежий лог показал,
  что CounterStrikeSharp выгрузил Warcraft при hot reload после ошибки mmap/parse
  изменённого файла. Исправления теперь находятся в общей `ZarayskMenu.Api.dll`, которая
  уже является зависимостью интегрированного меню.
- Остальные исправления 0.2.3 сохранены: рывок рейнджера, модель варвара,
  создание дронов механика и интеграция меню.

Автоматически проверены логика рывка, размер структуры, загрузка зависимостей,
JIT изменённых методов и неизменность остальных методов. Для окончательной
проверки нужны тесты на живом CS2-сервере.
