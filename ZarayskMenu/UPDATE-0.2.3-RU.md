# Warcraft: исправления навыков, сборка 0.2.3

Это обновление для уже установленного комплекта ZarayskMenu 0.2.2 с Warcraft 4.2.0.
Собрано с CounterStrikeSharp.API 1.0.375 и .NET 10. Версия API вашего сервера
в предоставленных логах отсутствует; проверьте `css_version` перед установкой.
Установка на другие сборки Warcraft, включая 4.4.0, не предусмотрена.

## Установка

1. Полностью остановите сервер.
2. Сохраните копию папки `game/csgo/addons/counterstrikesharp/plugins/WarcraftPlugin`.
3. Скопируйте папку `game` из архива в корень сервера с заменой файлов.
4. Запустите сервер заново. Не используйте hot reload для этого обновления.

В обновлении только три рабочих файла: `WarcraftPlugin.dll`,
`WarcraftPlugin.deps.json`, `ZarayskWarcraftFixes.dll` в папке WarcraftPlugin.
Базу данных и настройки заменять не нужно. Существующие меню, команды выдачи XP,
WeaponPaints и исправленная Linux SQLite остаются прежними.

## Что исправлено

- Общий урон навыков: раньше третий аргумент нативного TakeDamage был null.
  Теперь выделяется и инициализируется CTakeDamageResult по примеру native-тестов
  CounterStrikeSharp 1.0.375; память освобождается в finally.
- Данные атакующего: прежняя структура с указателем контроллера и смещением 152
  заменена структурой из того же примера API: pawn и player slot, смещение 136.
  Перед записью проверяются размер и соседние schema-поля. При несовместимом
  устройстве структуры операция прекращается с сообщением `unsupported engine layout`,
  а не записывает данные в неизвестную область памяти.
- Этот общий путь используют огненный шар мага, яд/зомби некроманта,
  стрелы рейнджера, атаки дрона и другие навыки. Их отдельные правила урона сохранены.
- Рывок: длительность 999999f не позволяла таймеру двигаться при 64 тиках/секунду
  из-за точности float. Новая длительность позволяет отсчитывать тики.
  Проверка ввода идёт каждый тик; новый нажим прыжка в воздухе даёт один рывок
  за полёт при изученном навыке и готовом cooldown. Импульс задаётся через Teleport.
- Варвар: убраны ссылки на тяжёлые модели, показывающие ERROR. Используется
  штатная модель игрока/агента с окраской класса. Это запасной вариант, не новая
  эксклюзивная модель варвара.
- Механик: модели трёх частей дрона устанавливаются до DispatchSpawn,
  а не отложенным таймером после создания физического объекта.
  Модель турели добавлена в предварительную загрузку.

## Проверено и что остаётся проверить

33 автоматические проверки: логика рывка, воспроизведение ошибки таймера,
структура данных атакующего и JIT изменённых методов и вспомогательного кода.
Патчер меняет 10 методов; 2296 остальных тел методов, включая интеграцию меню,
сохранены без изменения. Отдельно проходят существующие тесты меню.

На CS2-сервере сборка здесь не запускалась. Логи пользователя обрываются
на `Invoking native TakeDamage function`, что согласуется с найденной проблемой,
но не доказывает отсутствие других причин падения каждого класса.

После установки проверьте: огненный шар по противнику, яд и зомби некроманта,
урон стрел в области пинга, дронов механика при появлении/атаке/смерти владельца,
рывок двойным нажатием прыжка и приземление, внешний вид варвара за обе команды.
Если ошибка остаётся, нужны `css_version`, новая папка WarcraftPlugin/logs
и, при падении процесса, crash dump или последние строки консоли сервера.

Откат: остановите сервер и восстановите сохранённую папку WarcraftPlugin.

## Исходники

В полном архиве: `src/ZarayskWarcraftFixes`, `tools/GameplayPatch`, `gameplay-tests`.
Сборка: `tools/build-gameplay.ps1 -MenuPatchedWarcraft <DLL из комплекта 0.2.2> -Dotnet <dotnet10>`.
DLL должна находиться рядом со своими managed-зависимостями. Входная сборка
проверяется по SHA256; повторное применение патча к уже исправленной DLL запрещено.
