# Зарайск | Меню 0.7.5

Panorama-меню для Counter-Strike 2: прежний логотип, зелёные пункты, голубые номера и фиолетовое выделение. Компактные подсказки W/S/E/R/F помещаются в три строки.

Открыть: `!menu` в чате или `css_zmenu_open` в игровой консоли.
Настроить: **Управление меню → Управление клавишами / Управление мышью**.

- Клавиши: W/S — выбрать пункт, E — открыть, R — назад, удерживать F — закрыть.
- Мышь: курсор и ЛКМ. Активный режим отмечен галочкой.
- Режим запоминается до отключения игрока, включая переходы через общую API.
- Пользовательские бинды не переназначаются. Команда `css_zmenu_mouse` сохранена для совместимости.

## Что исправлено

CS2 Panorama отвергала соседний CSS-селектор `+`, из-за чего стиль меню не загружался. Он заменён явным классом второй колонки. Подсказки клавиш используют область 28×24 и отдельное поле буквы; убраны сжатие и яркая засветка при нажатии. Переключение управления выполняется непосредственно в серверном плагине, без зависимости от исполнения команды клиентом.

## Установка

Готовые файлы доступны в Releases. Скопируйте `server/game/csgo` в `game/csgo` сервера после остановки. При обновлении сохраните свои конфиги, а в разделе `help` файла `menu.json` перенесите два действия выбора управления из примера.

Общая `ZarayskMenu.Api.dll` должна находиться в `addons/counterstrikesharp/shared/ZarayskMenu.Api` единственным экземпляром. Изображения, скомпилированные XML/CSS и остальные клиентские ресурсы должны доставляться игрокам через обновлённый Workshop-аддон. GitHub Release не обновляет Steam Workshop автоматически.

Требуются CounterStrikeSharp с .NET 10 и поддержка `custom_hud_layout`. Для общего комплекта VIP/Cosmetics нужен API 376 или новее. Готовый общий комплект: [ZarayskCustomSuite](https://github.com/skazki7dkk-max/ZarayskCustomSuite/releases/tag/v2.3.7).

## Сборка и проверка

```powershell
dotnet build src/ZarayskMenu/ZarayskMenu.csproj -c Release
dotnet build src/ZarayskWarcraftMenu/ZarayskWarcraftMenu.csproj -c Release
dotnet run --project tests/Tests.csproj -- .
./tools/build-panorama.ps1 -Cs2 'C:/Program Files (x86)/Steam/steamapps/common/Counter-Strike Global Offensive'
```

Panorama компилируется Workshop Tools на Windows. Серверная DLL управляемая; отдельного `.so` для меню нет.

Проверено: 79 локальных проверок, сборка без ошибок/предупреждений, отображение реального меню на локальном Dust2. Три проверки зависят от установленного WeaponPaints и пропускаются, если его DLL отсутствует. Автоматическая проверка кликов мышью прервана вводом пользователя и пока не подтверждена. Удалённая серверная установка не выполнялась.
