## Требования и проверенные версии

На 28 сентября 2026:

- [Metamod:Source 2.0 dev build 1472](https://metamodsource.net/downloads.php?branch=master).
- [CounterStrikeSharp 1.0.375](https://github.com/roflmuffin/CounterStrikeSharp/releases/tag/v1.0.375). API этого релиза использует **.NET 10**, поэтому при первой установке берите Linux-сборку **with runtime**. Старое упоминание .NET 8 в README репозитория не соответствует целевой платформе API 1.0.375.
- [MultiAddonManager 1.6.1](https://github.com/Source2ZE/MultiAddonManager/releases/tag/v1.6.1) для доставки клиентских ресурсов. Совместимость всей связки с вашей сборкой сервера проверяется при запуске.
- CS2 с поддержкой `custom_hud_layout`.

DLL управляемая, подходит для Linux через рантайм CounterStrikeSharp. Отдельного Linux `.so` у меню нет: C++-плагины Metamod подключаются через серверный мост. CounterStrikeSharp нужен и в этом случае. Чистый Metamod без CounterStrikeSharp этим пакетом не поддерживается.

## Установка сервера Linux

1. Установите Metamod 1472, CounterStrikeSharp 1.0.375 с рантаймом и MultiAddonManager. Проверьте `meta list` и `css_plugins list` в консоли сервера.
2. Скопируйте содержимое `server/game/csgo/` архива в `game/csgo/` вашего сервера. Структура:

```text
addons/counterstrikesharp/plugins/ZarayskMenu/
    ZarayskMenu.dll
    ZarayskMenu.deps.json
    menu.json
addons/counterstrikesharp/shared/ZarayskMenu.Api/
    ZarayskMenu.Api.dll
```

3. Опубликуйте клиентский аддон по разделу ниже и добавьте его настоящий Workshop ID в `game/csgo/cfg/multiaddonmanager/multiaddonmanager.cfg`:

```cfg
mm_client_extra_addons "ВАШ_WORKSHOP_ID"
```

Если там уже есть аддоны, добавьте ID через запятую к существующему списку. Не используйте ID чужого UI-аддона: у него нет `zaraysk_menu.xml`.

4. Перезапустите сервер. Перезапустите клиент после обновления ресурсов Panorama, подключитесь и введите `!zmenu` в чат. В консоли клиента — `css_zmenu`.

`mm_client_extra_addons` доставляет только клиентские ресурсы; серверу эти ресурсы монтировать не нужно. Изменения списка применяются к новым подключениям. [Описание MultiAddonManager](https://github.com/Source2ZE/MultiAddonManager#convars).

## Workshop

Папка `workshop/zaraysk_menu/panorama/` содержит уже скомпилированные `.vxml_c` и `.vcss_c`. Исходники находятся в `panorama/`.

В Counter-Strike 2 Workshop Tools создайте аддон `zaraysk_menu`. Скопируйте исходную папку `panorama` в `content/csgo_addons/zaraysk_menu/`, а скомпилированную — в `game/csgo_addons/zaraysk_menu/`. Упакуйте и опубликуйте этот аддон средствами Workshop Tools, включив оба ресурса. Полученный ID используйте на сервере. Публикация требует вашего Steam-аккаунта и здесь не выполнялась.

Для повторной компиляции после изменений на Windows (PowerShell, Node.js и установленные Workshop Tools):

```powershell
./tools/build-panorama.ps1 -Cs2 'C:/Program Files (x86)/Steam/steamapps/common/Counter-Strike Global Offensive'
```

Скрипт копирует только файлы этого аддона в указанную установку CS2. Готовый VPK в архив не включён; упаковка/публикация выполняется в Workshop Tools.

## Управление меню

По умолчанию меню полностью управляется сервером без клиентского CFG: `W` — пункт выше, `S` — пункт ниже, `E` — выбрать, удерживать `F` 2 секунды — закрыть. Выбранная строка подсвечивается. При переходе за границу страницы меню автоматически меняет страницу.

`MOUSE3` (нажатие колёсика со стандартным назначением CS2) включает или выключает управление мышью. Нижняя панель показывает эти клавиши, переливается RGB-цветами и реагирует на нажатия.

Мышь в этом режиме не захватывается, чтобы CS2 отправляла серверу W/S/E/F. Если отключить `KeyboardNavigationEnabled` и включить `CaptureMouse`, снова будет доступно управление кликами. Для аварийного закрытия остаётся команда `css_zmenu_close` в клиентской консоли.

Чтобы использовать верхний цифровой ряд, игрок самостоятельно копирует `client/zaraysk_keys.cfg` в свой `game/csgo/cfg/`, сохраняет прежние бинды и выполняет `exec zaraysk_keys`. Сервер не может автоматически прописать бинды. F6 открывает/закрывает, F7 закрывает, 1–7 выбирают пункты, 8/9 навигация, 0 выход. NumPad отдельно не назначен.

CFG сохраняет стандартные команды `slot1…slot10` вместе с командами меню: поэтому при выборе цифрой возможно переключение оружия. Он перезаписывает прежние пользовательские назначения этих клавиш, F6 и F7 — после удаления верните свои сохранённые бинды. При закрытом меню команды `css_zm*` ничего не делают. Не обещается перехват обычных цифр без биндов или их работа во всех режимах клиентского фокуса; это входит в игровой тест.

Почему нужны бинды и аддон: ограничения `custom_hud_layout`, отсутствие произвольного клиентского JavaScript и недоступность `slot*` серверным listeners описаны в [исследовании CS2UIKit](https://github.com/nvmxre/cs2-ui-kit/blob/master/docs/GOTCHAS.md).

## Настройки

Рабочий конфиг: `addons/counterstrikesharp/plugins/ZarayskMenu/menu.json`. `config/menu.json` — исходный образец. Перечитать рабочий конфиг: `zm_reload` из консоли сервера/RCON. Неправильный конфиг не заменяет текущий. Активные меню закрываются при успешной перезагрузке.

| Поле | Значение |
|---|---|
| Title | Заголовок, по умолчанию «Зарайск \| Меню» |
| Theme | gold / ice / mono |
| Placement | standard / compact |
| PageSize | 1–7 |
| TimeoutSeconds | 5–600, бездействие до закрытия |
| ClickCooldownMs | 100–2000, защита от повторных кликов |
| CaptureMouse | Захват курсора; действует только при выключенном KeyboardNavigationEnabled |
| KeyboardNavigationEnabled | W/S — навигация, E — выбор, F — удержание для выхода |
| ExitHoldSeconds | 0.5–10, длительность удержания F |
| RebuildOnConnect | Пересоздание сущности после входа для обхода проблемы текста CS2 1.41.8.x |
| Menus | Меню, пункты, подменю, флаги и действия |

Пункт поддерживает `Id`, `Text`, `Permission`, `Enabled`, `CloseOnSelect` и одно действие: `Submenu`, `ServerCommand` или `Message`. Флаги используют систему админов CounterStrikeSharp. Пункты без прав скрываются; права перепроверяются при выборе. Страница выбора запоминается, чтобы изменение прав не превращало старую цифру в другое действие.

`ServerCommand` — заранее заданная серверная команда. Разрешены буквенно-цифровые токены и подстановки `{slot}`, `{userid}`, `{steamid}`. Точки с запятой, кавычки, переносы строк и свободный текст намеренно отклоняются. Будущая админка должна выполнять операции через собственный обработчик с повторной проверкой доступа.

Пункты «Администрирование» и «VIP-возможности» становятся активными при регистрации соответствующих подменю. Админка видна только обладателям `@css/generic`. Эти плагины пока не реализованы: меню не выдаёт деньги, оружие, баны или VIP само по себе.

## Границы относительно радара и чата

Стартовый профиль в условных координатах HUD: слева 12, сверху 310, ширина 300, низ полной страницы не ниже 705. Предполагаемые границы: низ радара 300, правый край 260, верх чата 790. Эти значения — настраиваемая исходная разметка, не считывание реальных границ вашего HUD.

`config/layout.json`: Left, Top, Width, RadarRight, ExtraRight, RadarBottom, ChatTop, RowHeight, FontSize, Background и Accent. `ExtraRight=57` — приближение 1,5 см при 96 DPI; физические сантиметры нельзя гарантировать для разных мониторов. `hud_scaling`, safe zone, разрешение и масштаб радара требуют сверки в игре.

`node tools/style.mjs` проверяет, что самая длинная страница не выходит за настроенные границы, и генерирует CSS. После изменения геометрии/цветов в этом файле нужна повторная компиляция и публикация Workshop. Готовые варианты `Theme`/`Placement` переключаются серверным JSON без публикации. Автоматического доступа к клиентским координатам миникарты и чата нет.

## API для будущих плагинов

`src/ZarayskMenu.Api` — общая сборка. Храните ровно одну копию в `shared/ZarayskMenu.Api`, не кладите отдельные копии в каждый плагин. На серверном потоке получайте `MenuService.Current`, регистрируйте меню через `Register` и освобождайте возвращённый `IDisposable` при выгрузке. Меню копируется при регистрации. Id глобально уникален. Callback получает игрока и id пункта.

Готовый компилируемый пример — `examples/ZarayskVipDemo`. Он добавляет подменю `vip`, выводит демонстрационные сообщения и проверяет `@css/reservation`, но не выдаёт реальные преимущества. После перезагрузки ядра перезагрузите зависимые плагины для повторной регистрации; не сохраняйте старый `MenuService.Current` навсегда.

Для C++/Metamod описан протокол в `examples/metamod/README.md`: ядро вызывает серверные команды; Metamod-плагин может открыть меню командой `zm_open slot steamid menu`. Это интеграция плагинов через CounterStrikeSharp, не отдельный C++ ABI и не независимый Metamod-плагин.

## Сборка и проверки

Нужен .NET SDK 10:

```text
dotnet build src/ZarayskMenu/ZarayskMenu.csproj -c Release
dotnet run --project tests/Tests.csproj -c Release -- /absolute/path/to/ZarayskMenu
dotnet build examples/ZarayskVipDemo/ZarayskVipDemo.csproj -c Release
node tools/style.mjs
```

Для сборки структуры `server/` на Windows: `tools/build.ps1`. На Linux скопируйте собранные DLL в пути из раздела установки. Фреймворки Metamod/CSS/MultiAddonManager в этот архив не включены.

После установки проверьте мышь и цифры, переход на страницу с >7 пунктами, Back/Next/Exit, закрытие по тайм-ауту, смерть, смену карты, повторный вход в тот же slot, обновление прав и выгрузку ядра. Сравните HUD на 16:9 и 4:3 и при используемом `hud_scaling`. Проверьте, что игрок без прав не может выполнить native-действие прямой клиентской командой. Только после этого переносите на основной сервер.

## Источники реализации

API/версии проверены по официальным исходникам [CounterStrikeSharp v1.0.375](https://github.com/roflmuffin/CounterStrikeSharp/tree/v1.0.375) и релизам выше. Его библиотека в пакет не встроена: здесь небольшой собственный адаптер `CCSCustomHudLayout` с нужными именно меню событиями и очисткой.
