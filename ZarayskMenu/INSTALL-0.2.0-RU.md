# ZarayskMenu 0.2.0 + Warcraft 4.2.0 — единое меню

## Что готово

- `!menu` / `/menu` / `css_menu` — главное меню. Повтор в главном меню закрывает его; из раздела возвращает в главное.
- `!zmenu` сохранена для старых биндов.
- `!war` — раздел Warcraft с быстрыми переходами.
- `!warcraft`, `!wc`, `!wcmenu`, `!class`, `!skills`, `!shop` — игровые страницы Warcraft теперь рисуются ZarayskMenu.
- `!helpwar` — русская справка: основы и 56 навыков 14 штатных классов.
- Профиль, классы, навыки, магазин, инвентарь и подтверждения сброса используют одно оформление и мышь.
- В магазине сначала открывается карточка с полным названием, ценой и описанием; покупка — отдельным пунктом.
- `css_zmenu_close` — аварийное закрытие; `css_zmenu_status` — диагностика.

Мышь работает без клиентских биндов. Цифры 1–7, 8 (назад), 9 (далее), 0 (выход) требуют установки `client/zaraysk_keys.cfg`. Сохраните свои прежние назначения: CFG перезаписывает их. W/S/Space из старого меню Warcraft больше не управляют его окнами. `client/warcraft_keys.cfg` — отдельный необязательный набор F6/F7/F8/X.

## Установка

1. Остановите сервер. Сохраните прежние папки плагинов, конфигурации и базы Warcraft.
2. Требуется CounterStrikeSharp API **1.0.375 с .NET 10**, Metamod и доставка клиентского аддона ZarayskMenu. Серверные фреймворки в архив не включены.
3. Скопируйте содержимое `server/game/csgo/` в `game/csgo/` сервера с заменой DLL. Обновите три папки плагинов: `ZarayskMenu`, `ZarayskWarcraftMenu`, `WarcraftPlugin`, а также `shared/ZarayskMenu.Api/` внутри `addons/counterstrikesharp/`.
4. Не оставляйте второй экземпляр Warcraft в другой папке плагинов. Не заменяйте конфигурацию и базы в `configs/plugins/WarcraftPlugin/`: этот пакет их не содержит.
5. Клиентам нужны ресурсы **zaraysk_menu**, уже использованные вашим меню. В `workshop/zaraysk_menu/` приложены прежние скомпилированные ресурсы. Если они уже доставляются, новая публикация для этой версии не нужна. Если нет — опубликуйте аддон через CS2 Workshop Tools и добавьте его настоящий ID к `mm_client_extra_addons` в MultiAddonManager. Доставка ресурсов на ваших клиентах здесь не проверена.
6. Отдельный `warcraft_rpg_ui` для этой сборки меню не используется. Не удаляйте другие аддоны, необходимые игровым моделям и эффектам.
7. Перезапустите сервер, переподключитесь. Проверьте `css_plugins list`, затем `!menu` и `!helpwar`. При ручной загрузке: сначала ZarayskMenu, затем ZarayskWarcraftMenu и WarcraftPlugin. Модуль справки автоматически подключается к ядру, в том числе после его перезагрузки.

## Приоритет и другие плагины

Пока меню открыто, ядро закрывает активные меню CounterStrikeSharp и совместимые CS2MenuManager, отключает чужой захват мыши и удерживает собственный с интервалом 0,25 сек. После закрытия приоритет прекращается. Тайм-аут, смерть, начало раунда и смена карты освобождают меню. Закрытые чужие меню автоматически не восстанавливаются.

Warcraft больше не регистрирует `menu`/`css_menu` и не конкурирует с `!menu`. Не назначайте эту команду другим плагинам. Абсолютный приоритет над любыми неизвестными DLL, обработчиками чата и HUD технически не гарантируется.

Другие плагины подключаются через `ZarayskMenu.Api.IMenuService` либо фиксированные серверные команды `ServerCommand` в `menu.json`. При переходе к внешнему интерфейсу оставляйте `CloseOnSelect: true`, чтобы приоритет не закрыл его. Для каждого стороннего плагина нужен его API или известная команда. Админ/VIP-пункты исходного меню активируются при подключении соответствующих модулей.

## Справка и игровые действия

Файл `plugins/ZarayskWarcraftMenu/warcraft.json` содержит инструкции и быстрые команды в контексте игрока. В этой версии Warcraft используются команды `warcraft`, `class`, `skills`, `shop` без `css_`. Проверки игровых условий сохраняет Warcraft. Для перечитывания справки перезагрузите ZarayskWarcraftMenu.

Бинд: `bind x ultimate` в консоли клиента. Ультимейт изучается на 16-м уровне и требует готовой перезарядки. Дымовая бомба разбойника автоматическая. Рывок мага, повторный прыжок рейнджера, decoy-ловушки и инструмент инженера описаны отдельно. Пользовательские герои и изменения баланса требуют дополнения справки.

## Изменения DLL Warcraft

Серверный архив не содержал исходного проекта. Выполнен воспроизводимый IL-патч исходной DLL:

- `WarcraftPlugin.Menu.MenuManager.OpenMainMenu` передаёт меню в `ZarayskMenu.Api.MenuService.OpenExternal`;
- `CloseMenu` закрывает его через то же ядро;
- `AddUniqueCommand` пропускает имена `menu` и `css_menu`.

Все **2303 остальных тела методов** сравнены с исходной DLL и не изменены. Колбэки RPG, экономика, базы, опыт, классы и подтверждения сброса сохранены. Интерфейс Warcraft зависит от общей API и работающего ядра. Без ядра выводится сообщение о недоступности меню; сама RPG-логика при выгрузке меню не выключается.

SHA256 исходной DLL: `2F722B5A7B21DD82DBC8672A3E3803D33F5EBCDDBC0B7CD987A08F3A71538BC1`.
Патчер `tools/WarcraftPatch` отказывается изменять другую DLL. Для новой версии Warcraft потребуется новая адаптация.

## Сборка

Нужны .NET SDK 10 и NuGet. Из корня исходников:

```powershell
./tools/build.ps1
dotnet run --project tests/Tests.csproj -c Release -- (Get-Location).Path
dotnet run --project tools/WarcraftPatch/WarcraftPatch.csproj -c Release -- ORIGINAL_DLL src/ZarayskMenu.Api/bin/Release/net10.0/ZarayskMenu.Api.dll OUTPUT_DLL
```

Зависимости Warcraft должны лежать рядом с оригинальной DLL. `build.ps1` собирает ядро и справку; патч Warcraft запускается отдельно. Установочный пакет уже содержит изменённую DLL. API должна лежать в `shared/ZarayskMenu.Api`, без отдельных копий в папках плагинов.

## Проверки

Ядро и справка собраны без ошибок и предупреждений. Автотесты проверяют конфиги, CS2MenuManager, запрет составных команд, структуру Panorama, 56 навыков и длину строк. Патчер проверяет оба перенаправления и отсутствие изменений остальных методов.

Живой сервер CS2 не запускался. Перед основной установкой проверьте мышь, игровые страницы, покупки, недостаток денег, закрытие, смерть, переподключение, смену карты и hot reload. Проверьте отсутствие двойного вызова `!menu` с вашим набором плагинов.

Семантика `css_`-команд: [официальная документация CounterStrikeSharp](https://docs.cssharp.dev/examples/WithCommands.html).
