# Проверка сборки 0.2.0 — 29 сентября 2026

- .NET SDK 10.0.401; CounterStrikeSharp.API 1.0.375.
- ZarayskMenu.Api, ZarayskMenu и ZarayskWarcraftMenu: Release/net10.0, без ошибок и предупреждений.
- 35 автоматических проверок завершились успешно: конфиги, CS2MenuManager, отказ при недопустимых командах, Panorama, 59 страниц справки (56 навыков + 3 вводных раздела), 14 групп классов, строки не длиннее 29 символов, автоматический ультимейт разбойника, актуальный рывок мага.
