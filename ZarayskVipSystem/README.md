# Zaraysk VIP System 2.3.0

Изменения 2.3.0: у каждой VIP-группы появился настраиваемый `CustomSkinIds`; пункт «Кастомные скины VIP» открывает этот белый список в ZarayskMenu. Компактный HUD урона суммирует все последовательные попадания и держится настраиваемые 2–4 секунды (`DamageHudSeconds`, стандартно 3). Последний удар показывается через `+`.

Самостоятельный C#-плагин CounterStrikeSharp для ZarayskMenu. Никакого VIP Core/Utils/sql_mm или кода Pisex нет.

Реализовано:

- HP/броня только со 2-го раунда (`BonusStartRound`);
- деньги каждый раун, шлем, дефузер, bhop, защита от падения;
- шприцы каждый N-й раун с настраиваемым количеством;
- тег в TAB, цвета тега/ника/сообщения в чате;
- индикатор урона, цветной kill-screen и kill-feed с headshot/no-scope/wall/smoke/blind/air/assist/domination/revenge/wipe;
- FOV, RGB-модель, RGB-смок, ауры и трейлы гранат;
- выбор максимальной горизонтальной скорости bhop;
- FOV и все цвета выбираются в отдельных подменю; `R` возвращает на предыдущий уровень общего меню;
- кастомные модели для каждой группы задаются массивом `CustomSkinIds` из ID каталога ZarayskCosmetics;
- MySQL-сроки, группы и личные настройки игрока.

Реген HP/брони, spawn-money, HP за убийство и деньги за убийство удалены.

```text
!vip
css_zvip_status
css_zvip_add <steam64> <group> <days, 0=навсегда> [name]
css_zvip_remove <steam64>
css_zvip_reload [steam64]
```

Ауры и трейлы задаются путями `.vpcf` в конфиге. Плагин добавляет их в precache на старте карты.
