# Zaraysk Custom Suite for CS2

Кастомная серверная система для Counter-Strike 2:

- Panorama-меню Zaraysk с управлением W/S/E/R/F и мышью;
- VIP-система с накопительным HUD урона;
- кастомное оружие по команде `!cw` без обязательного VIP;
- шляпы, рюкзаки, ауры и Dota-питомцы;
- настройка доступных кастомных скинов для каждой VIP-группы.

## Готовая установка

Скачайте архивы со страницы **Releases**:

- `ZarayskCustomSuite-2.3.7-SERVER.zip` — файлы сервера;
- `ZarayskCustomSuite-2.3.7-WORKSHOP.zip` — готовый VPK и исходники Workshop;
- `ZarayskCustomSuite-2.3.7.zip` — полный комплект.

Подробная русская инструкция находится внутри полного архива в файле
`ПРОЧИТАЙ.txt`.

## Требования

- CounterStrikeSharp API 376 или новее;
- .NET 10;
- MySQL/MariaDB либо JSON-режим для локального теста;
- клиентский Workshop-аддон с Panorama и кастомными ресурсами.

## Основные команды

- `!menu` — главное меню;
- `!vip` — VIP-меню;
- `!skins` — личный инвентарь косметики;
- `!cw` — кастомное оружие;
- `css_zskin_give <steam64> <model_id> <quantity> <days>` — выдать предмет;
- `css_zskin_take <steam64> <model_id> <quantity>` — забрать предмет.

## Исправления и проверка 2.3.7

- Panorama теперь всегда принудительно компилируется: устаревший HUD больше не остается в VPK из-за времени файлов.
- Кастомная модель применяется и к world model, и к viewmodel в руках, с восстановлением исходной модели.
- HUD урона не перерисовывается каждые 150 мс: сумма обновляется только новым попаданием и держится 2–4 секунды.
- Добавлены отдельные звуки открытия, перемещения, выбора, возврата и закрытия меню.

- 79 локальных тестов меню и 17 тестов VIP/Cosmetics;
- сборка без предупреждений и ошибок;
- Workshop VPK: 723 файла, CRC каждого файла проверен;
- каталог: 14 шляп, 14 рюкзаков, 41 питомец и 72 ауры.

Большие игровые ассеты не хранятся в Git-истории — они опубликованы в Release.


## Меню 0.7.5

Зарайск 2.3.7: меню 0.7.5 с компактными подсказками и выбором управления.

В «Управление меню» добавлены пункты «Управление клавишами» и «Управление мышью». Выбор выполняется внутри плагина, сохраняет подменю и историю возврата. Активный режим отмечен галочкой и запоминается до отключения игрока. Подсказка MOUSE4 заменена текущим режимом; пользовательские бинды не меняются.

Клавиши W/S/E/R/F компактные, с отдельной областью для букв, мягким свечением и без сжатия/засветки при нажатии. Устранён CSS-селектор `+`, из-за которого CS2 не загружала весь стиль Panorama и меню было невидимым.

Состав: ZarayskMenu 0.7.5, VIP 2.3.1, Cosmetics 1.3.1, общая API, клиентская Panorama и пересобранный Workshop VPK. VIP и Cosmetics взяты из комплекта 2.3.6.

Файлы:

- `ZarayskCustomSuite-2.3.7.zip` — полный комплект.
- `ZarayskCustomSuite-2.3.7-SERVER.zip` — серверные файлы.
- `ZarayskCustomSuite-2.3.7-WORKSHOP.zip` — VPK и исходники Workshop.

При обновлении требуется обновить DLL, раздел `help` в своём `menu.json` и клиентские ресурсы. Сохраните свои конфиги и базы. Файлы на GitHub сами по себе не обновляют опубликованный Steam Workshop: обновите Workshop-аддон из приложенного пакета.

Проверка: сборка без ошибок/предупреждений; 79 локальных проверок меню; CRC ресурсов VPK; меню и компактные клавиши видны в реальной локальной CS2 на Dust2. Автоматическая проверка кликов мышью была прервана вводом пользователя; работа переключателя реализована, полный сценарий кликов пока не подтверждён. На удалённый игровой сервер установка не выполнялась.
