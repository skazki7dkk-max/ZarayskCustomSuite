# Zaraysk Cosmetics

Версия 1.3.0 добавляет рабочее поведение питомцев: плавное следование за
владельцем, idle-анимацию и автоматическую высоту с парением для Dota-моделей
`flying`/`_fly`. Поля `PetFlying`, `PetFollowSmoothing` и
`PetIdleAnimation` позволяют переопределить поведение отдельной модели.

Отдельный CounterStrikeSharp-плагин инвентаря косметики. Поддерживает модели персонажей, оружия, шапки, рюкзаки, питомцев и ауры. Каждый предмет выдаётся на SteamID с количеством и сроком; разные слоты можно надевать одновременно. Выбор идёт через ZarayskMenu.

```text
!skins
!cw
css_zskin_give <steam64> <model_id> <quantity> <days, 0=навсегда>
css_zskin_take <steam64> <model_id> <quantity>
css_zskin_reload
```

`!cw` открывает только принадлежащее игроку кастомное оружие и не требует VIP. Выданные предметы, количество, срок и выбранное оружие сохраняются в MySQL (или в локальном JSON при явном тестовом режиме).

`WorkshopId` хранится в конфиге для связи с паком. Файлы Workshop-аддона должны быть установлены на сервере и доставлены клиентам; плагин прекеширует `ModelPath` и `ParticlePath`.

В готовом `ZarayskCosmetics.example.json` уже описаны все 164 варианта из переданных архивов. Перед установкой укажите доступ к MySQL и переименуйте файл в `ZarayskCosmetics.json`.
