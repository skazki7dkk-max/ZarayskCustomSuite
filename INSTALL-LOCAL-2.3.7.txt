ЛОКАЛЬНАЯ УСТАНОВКА ЗАРАЙСК 2.3.7

Этот архив предназначен для Windows и локального сервера на вашем ПК.
Содержит меню 0.7.5, VIP 2.3.1, Cosmetics 1.3.1, общую API и все 723
клиентских ресурса без VPK-частей в корне аддона.
Metamod и CounterStrikeSharp с runtime должны быть заранее установлены.

1. Закройте CS2.
2. Запустите Install-Local.ps1 в PowerShell.
   При нестандартной папке игры укажите -Cs2Path 'путь к CS2'.
3. Запустите Start-Local.ps1: откроется локальная Dust2 на 127.0.0.1:27017.
4. В чате игры напишите !menu. Выбор управления находится в «Управление меню».

Установщик раскладывает файлы game по папкам игры, сохраняет существующие
настройки VIP/Cosmetics и базы, переносит только два пункта выбора управления
в существующий menu.json. Заменяемые файлы сохраняются в zaraysk-backups.
Свои admins.json, SteamID и данные игроков в архив не включены.
Новые настройки используют явный локальный JSON-режим. На рабочем удалённом
сервере используйте серверный архив и свои производственные настройки.

ВАЖНО О VPK:
Не копируйте 3809867620_000.vpk, _001.vpk, _002.vpk и _dir.vpk в корень
game/csgo_addons/zaraysk_menu для такого локального запуска. CS2 может
принять часть за самостоятельный архив и показать «VPK directory ... corrupt».
В этом архиве уже лежат распакованные ресурсы в characters/materials/models/
panorama/particle/particles/weapons — дополнительных VPK не требуется.
Готовый VPK из отдельного Workshop-архива предназначен для соответствующего
Workshop/серверного загрузчика; Steam Workshop этот архив не публикует.

Компактное меню проверено на локальной Dust2, 79 проверок меню прошли.
Полный сценарий кликов мышью пока не подтверждён автоматически.
